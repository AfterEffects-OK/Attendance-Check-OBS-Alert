# 出席登録OBSオーバーレイ通知システム

Googleフォームやスプレッドシートへの出席登録をリアルタイムに検知し、OBS（Open Broadcaster Software）上にアニメーション付きの通知カードとしてポップアップ表示させるためのシステムです。

## 構成コンポーネント

1. **Googleスプレッドシート & Google Apps Script (GAS)**
   * 出席データが蓄積されるスプレッドシート [出席登録]
   * 新規行の追加を監視し、最新の出席者名とタイムスタンプをJSON形式で返却するWeb API（`doGet`）[出品登録OBSオーバーレイ通知]
2. **OBSブラウザソース（HTML / CSS / JavaScript）**
   * 定期的にGASのエンドポイントへポーリング（定期通信）を行い、新しい出席データを検知すると画面左下にスライド＆フェードインで通知カードを表示します。
   * 不透明な背景色と軽量なアニメーション処理（GPU最適化）により、OBS上でのカクつきを抑えたスムーズな描画を実現しています。

---

## 導入・設定手順

### 1. Google Apps Script (GAS) 側の準備
1. 対象の [出席登録スプレッドシート] に紐づく [Apps Scriptプロジェクト] を開きます。
2. コードエディタに最新の配信プログラム（`doGet` 関数）が記述されていることを確認します。
3. 右上の **「デプロイ」 > 「新しいデプロイ」** を選択します。
   * 種類の選択: **「ウェブアプリ」**
   * アクセスできるユーザー: **「全員」**
4. 発行された**ウェブアプリのURL**をコピーします。

### 2. OBS 側の設定
1. OBS Studioを開き、シーンに「**ソース**」の「**＋**」ボタンから「**ブラウザ**」を追加します。
2. プロパティ画面で以下のように設定します。
   * **URL**: ローカルに保存した `index.html` のパス（またはホストしたURL）を指定します。
   * **幅**: `1920` （配信解像度に応じて調整）
   * **高さ**: `1080`
   * **カスタムCSS**: （デフォルトのままでOKです）
3. ※コード内の `GAS_WEB_APP_URL` 変数に、手順1で取得したウェブアプリのURLが正しく貼り付けられていることを確認してください。

## 主な仕様・特徴

* **自動ポーリング**: 約3秒おきにスプレッドシートの更新行（`rowCount`）を監視し、新規追加を自動検出します。
* **軽量なアニメーション**: 不透明背景（ソリッドカラー）を採用し、`will-change` プロパティやハードウェアアクセラレーションを活用することで、OBSのブラウザソース内でも描画落ちやカクつきを防ぎます。
* **コンパクトなデザイン**: 視認性を保ちつつ上下のパディングを詰め、画面を圧迫しないスリムな通知カードデザインになっています。
